# TANSTAAFL Labs: project reports

*There Ain't No Such Thing As A Free Lunch.*

Write-ups of how TANSTAAFL Labs projects were built: by teams of AI agents from several model families (Claude,
Codex, Grok, Gemini), working under one human owner, with every piece of work reviewed by a different model family
before it merges. Each report covers what was built, who did what, how the work flowed, what went wrong and how it was
caught, and what was learned. The failures are included on purpose.

The source repositories are private. These reports are compiled from their specs, review records and git history.

| Project | What it is | Report |
| --- | --- | --- |
| **SHAWN PLM** | An on-prem product lifecycle management system for capital-equipment manufacturers. 204 specs, 1,237 commits, four model families | [projects/shawn-plm](projects/shawn-plm/README.md) |
| **Fiver** | A stereo five-band analog EQ: schematic to order-ready PCB in three days, with KiCad and ngspice run headless | [projects/fiver](projects/fiver/README.md) |
| **Teardrop (Slipstream-II)** | A 3D-printed desktop loudspeaker and kinematic tripod stand, designed in parametric CAD by three model families | [projects/teardrop](projects/teardrop/README.md) |
